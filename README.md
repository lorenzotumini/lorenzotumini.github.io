# Personal website

The site is generated by Pelican, a small Python static-site generator. The
published result is ordinary HTML and CSS with no client-side framework.

## Set up

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Write and preview

Articles are Markdown files under `content/articles/`. Personal information is
in `content/pages/home.md`, and the project list is in `data/projects.toml`.

To rebuild automatically and preview at `http://localhost:8000`:

```powershell
python -m pelican content -s pelicanconf.py --autoreload --listen
```

To generate the site once:

```powershell
python -m pelican content -s pelicanconf.py
```

The generated files are written to `output/`. Do not edit them directly.

Reusable HTML lives in `theme/templates/`; the complete visual design is in
`theme/static/css/style.css`.
